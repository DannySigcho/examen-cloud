¿Qué es Cloud Computing?

Cloud Computing o computación en la nube es una tecnología que permite acceder a servidores, almacenamiento, aplicaciones y servicios informáticos mediante Internet.

☁️ CLOUD COMPUTING ☁️

Modelos de servicio

SaaS

💻

Software como servicio. Permite utilizar aplicaciones mediante Internet sin instalarlas localmente.

Ejemplo: Gmail y Google Drive.

PaaS

⚙️

Plataforma como servicio. Ofrece herramientas para desarrollar y ejecutar aplicaciones.

Ejemplo: Google App Engine.

IaaS

🖥️

Infraestructura como servicio. Proporciona servidores, redes y almacenamiento virtual.

Ejemplo: Amazon EC2.

Virtualización

🔄

Es una tecnología que permite crear versiones virtuales de servidores, sistemas operativos, redes y almacenamiento utilizando recursos físicos.

Docker

🐳

Docker es una plataforma que permite crear, distribuir y ejecutar aplicaciones dentro de contenedores. Facilita la instalación y ejecución de programas en diferentes sistemas.
